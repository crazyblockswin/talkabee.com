Backups & Deployment

Scene changes can be saved locally while editing. Use the current Master Editor publishing workflow to publish Adventures. JSON files are for backup/import. The design settings live in browser storage, so a website-wide default must also be published in the engine for all visitors.

Enhanced Piper is an integration point only: the existing Piper runtime must be connected separately. Standard browser speech works without it.
