Talk A Bee — Translation Studio

Separate from Master Studio. Nothing on your site changes until you deliberately restore and publish the finished backup.

1. Load your complete Adventure backup

In Master Studio choose Backup All Adventures, then select that JSON here. Keep the original backup safe.

2. Translate missing text

Existing translations are locked. This studio fills missing translations only. It never replaces completed text.

Uses the free MyMemory online service. Results can be imperfect; Norwegian support and daily limits must be tested. One request at a time to avoid overloading the service.

3. Review and download

Load a backup to begin.

This downloads ONLY new translations, not Adventures. In Master Studio use Import Missing Translations Patch, then Publish All Adventures after reviewing. Do NOT use Restore All Adventures Backup for this patch. Translation quality still needs review.
